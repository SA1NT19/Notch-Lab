# Notch Lab

Версия: **0.19.12**

Notch Lab — приложение для macOS с инструментами в панели у верхнего края экрана.

- Управление музыкой и микшер громкости приложений.
- История буфера обмена и мобильный буфер рядом с курсором.
- Конвертация файлов, метаданные и мобильная конвертация.
- Расстановка окон по готовым и собственным раскладкам.
- Камера, редактор изображений и очистка диска.
- Настройка оформления и порядка разделов.

**Система:** Apple Silicon, macOS 14 или новее; микшер требует macOS 14.2 или новее. Проверено на macOS 15.6.

**Установка:** скачайте архив из Releases, распакуйте и перенесите Notch Lab в «Программы». Для отдельных функций потребуются разрешения macOS.

Сборка подписана локальным сертификатом и не нотариализована Apple. macOS может остановить её при первом запуске; проверьте издателя и следуйте [инструкции Apple](https://support.apple.com/ru-ru/102445). Для сложных документов Word и презентаций доступен отдельно устанавливаемый локальный Office-модуль.
